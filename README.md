## 使用方法

1. 备份存档，启动游戏并进入战役。
2. 使用 Cheat Engine 附加 `The Pegasus Expedition.exe`。
3. 打开 V4 `.CT` 文件并激活 `01 - MASTER`。
4. 根据需求单独使用六种资源指针、舰队／特工无限行动力以及战斗无敌。
5. **不要启用即时修复或即时建造相关条目。**

## 已知限制与风险

- V2 的行动力 `999/99` 修改曾使舰队与特工无法移动，请勿使用旧版脚本。
- 早期批量执行 `StarFleet.RepairByAmount` 曾造成 Mono 超时和游戏闪退；此方案已弃用。
- V4 的“快速修理”不是“即时完全修复”，对原本只需 1 回合维修的舰队基本没有作用。
- 当前建造加速也不等于真正即时完成，可能仍需要正常回合结算。
- 每次重启游戏后应重新附加进程并激活主脚本，重新解析动态指针。
- 修改内存可能造成游戏异常或存档损坏，请始终备份存档。
